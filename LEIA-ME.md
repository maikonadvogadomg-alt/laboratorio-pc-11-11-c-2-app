# 🔬 Laboratório para PC (.exe)

É o mesmo Laboratório do celular, numa janela própria do Windows, **com o terminal do computador**:
a aba 💻 Terminal usa o terminal e a ponte do próprio programa (não precisa do Termux).
Os projetos que você manda para o terminal ficam em **C:\Mini-SK\NOME** (a mesma pasta do Mini SK).

## Como gerar o .exe (igual ao Mini SK)
1. No Mini SK: abra este zip como projeto → 🐙 GitHub → criar repositório (privado) → enviar.
2. No GitHub: **Actions** → "Programa .exe para Windows" → **Run workflow**.
3. Quando ficar verde: **Releases** → baixe **Laboratorio-Instalar.exe** (ou o "sem-instalar").

## Junto com o Mini SK
- O Laboratório usa a porta **7690**; o Mini SK usa a **7680**: os dois abrem ao mesmo tempo.
- Também dá para abrir o Laboratório **pelo Mini SK do PC** (💻 Terminal → 🌐 Abrir como app), sem gerar outro .exe.

## O que vem junto (do Mini SK para PC)
🩺 Saúde do computador não aparece aqui (é do Mini SK), mas vêm: o terminal do PC, a ponte de arquivos,
o 🦙 Ollama ligando sozinho, o 🌐 Navegador de verdade, a placa de vídeo e o instalador que fecha o antigo sozinho.
